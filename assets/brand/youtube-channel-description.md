# YouTube channel description

Paste-ready copy for the Kalamari channel. The long version goes in **YouTube Studio
→ Customisation → Basic information → Description** (1,000 character limit). The
short version is for the header / About preview, which truncates after roughly two
lines.

## Long description

```
Kalamari is an independent app studio in Canberra, Australia.

We make calm, useful apps for everyday life, and this is where we show them working.

PuppyPulse — a puppy tracker for the first months at home. Potty, meals, naps, walks, health, and training in a tap, shared with your household.

Whysper — reminders that carry the reason you set them, so each task arrives with its purpose attached.

Both are coming soon to Google Play.

No advertising, no ad tracking, no growth hacks. Just software that respects the people using it.

kalamari.club
```

## Short version (header preview)

```
Independent app studio in Canberra, Australia. Calm, useful apps for everyday life, and short videos of them working.
```

## Notes

- **One line dates:** "Both are coming soon to Google Play." Change it on launch day
  to the store links. Nothing else in the description needs touching.
- **The first paragraph is the snippet.** YouTube truncates the About preview after
  roughly two lines, so line one is a complete sentence that names the studio, the
  country, and the category. Everything after it is a bonus.
- **No subscribe ask.** The channel exists to back the Play Store listings, not to
  build an audience; a call to action would be the wrong voice for a studio that
  promises "no growth hacks". The banner's copy does the inviting.
- **Serial commas and Australian spelling** follow the website's existing copy.
- **The URL is a last line, not a link panel.** Add `kalamari.club` in Studio's
  Links section as well, where it is clickable and more visible.
